# FixIt — AI-Powered Repair, Reuse & Maintenance Platform

### **Tagline: “Toota Hai? Phekna Nahi. FixIt Karo.”**

FixIt is an AI-powered problem-to-solution platform designed to help users understand, repair, reuse, and maintain broken or damaged products instead of immediately throwing them away.

Users can **show their problem** through a photo, video, camera, voice, or text. FixIt analyzes the problem and provides a suitable solution such as DIY repair guidance, required spare parts, technician assistance, repair-vs-replace recommendations, or reuse and second-life ideas.

---

## 🚀 Key Features & Highlights

### 🔍 AI-Powered Problem Diagnosis

Users can submit a broken or damaged product using:

* Camera
* Photo
* Video
* Voice
* Text description
* Product name/model

FixIt analyzes the submitted problem and provides an understandable diagnosis.

### 🛠️ Repairability Analysis

The platform provides:

* Repairability Score
* Estimated repair difficulty
* Estimated repair time
* Approximate repair cost
* Required tools
* Required spare parts
* DIY feasibility

### 📖 DIY Repair Assistant

For simple and safe problems, FixIt provides step-by-step repair guidance with instructions, visuals, and safety warnings.

For complex or potentially dangerous repairs, the platform recommends professional assistance instead of encouraging unsafe DIY work.

### 👨‍🔧 Technician Marketplace

Users can find suitable technicians based on:

* Category
* Location
* Availability
* Experience
* Ratings & reviews
* Verification status
* Estimated service cost

Users can view technician profiles and book repair services.

### 🔩 Spare Parts Assistance

FixIt identifies potentially required spare parts and provides:

* Part name
* Product/model compatibility
* Genuine or compatible options
* Estimated price
* Online/local purchasing options

### ⚖️ Repair vs Replace

FixIt helps users compare repair and replacement costs.

Example:

**Repair Cost:** ₹800
**Replacement Cost:** ₹5,000

→ Repair may be considered.

The platform provides the comparison so users can make an informed decision.

### ♻️ Reuse & Second Life

If a product is difficult or uneconomical to repair, FixIt can suggest alternative ways to reuse or repurpose it.

Examples:

* Old chair → Plant stand
* Old tyre → Utility item
* Wooden parts → Storage/Table
* Old electronic components → DIY projects

### 🛒 Second-Life Marketplace

Users can list:

* Broken products
* Spare parts
* Reusable components
* Refurbished products

A product that is no longer useful to one person may still have value as a repairable item or source of components.

### 📱 Mobile-Friendly Web Experience

FixIt is designed as a responsive web platform that works across:

* Mobile phones
* Tablets
* Laptops
* Desktop computers

Users can access the platform directly through a web browser without installing a separate application.

### 🚨 FixIt Now

A future emergency service concept for urgent repair requirements such as bike, car, appliance, or other time-sensitive problems.

The system can help connect users with nearby available technicians.

## 🎯 Core Problem

People often throw away products because they:

* Do not know what is wrong with the product
* Do not know whether it can be repaired
* Cannot identify the required spare part
* Do not know the approximate repair cost
* Cannot find a suitable technician
* Do not know how to safely perform simple repairs
* Assume replacement is easier than repair

FixIt brings these solutions together in a single platform.

## ▶️ How to Run Locally

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project

```bash
cd FixIt
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in the terminal.

### 5. Build for production

```bash
npm run build
```
